# Muhammad Ali Afzaal — Portfolio

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For a local development server, run `python -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **public** repository named `ali-tech427.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish. Your portfolio address will be:
   `https://ali-tech427.github.io`
6. Open the URL in an incognito/private browser to confirm it is public, then add it to LinkedIn → Contact info → Website.

## Before publishing
- Review the content and ensure every experience and technology listed accurately reflects your work.
- Add project screenshots or live demo/source links only when you have permission and the links are public.
- Do not upload private company code, screenshots containing patient data, credentials, or confidential project information.
- The phone number and email are displayed publicly on the contact section. Remove the phone link if you prefer email-only contact.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive visual design
- `script.js` — mobile navigation, scroll reveal, and copy-email interaction

No build step or paid hosting is required.
